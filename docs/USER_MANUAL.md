# Qandang User Manual (Panduan Pengguna)

## 1. Pendahuluan
Qandang adalah sistem monitoring ternak kambing berbasis digital. Manual ini membantu Anda memahami cara mengelola data ternak menggunakan Web Dashboard dan Mobile App.

## 2. Pendaftaran Ternak
### Melalui Web
- Masuk ke menu **Data Kambing**.
- Klik **Tambah**.
- Isi data lengkap (Nama, Jenis, Silsilah).
- Kode QR akan dihasilkan otomatis.

### Melalui Mobile
- Buka menu **Ternak**.
- Klik tombol **Tambah Ternak** di pojok kiri bawah.
- Isi data dan simpan.

## 3. Identifikasi & Scanning
### Mobile App
- Klik tombol **Scan QR** di pojok kanan bawah.
- Arahkan ke tag telinga kambing.
- Info cepat akan muncul (Berat terakhir, Status kesehatan).
- Anda bisa langsung input berat badan baru dari layar ini.

## 4. Analisis Prediksi AI (Fitur Unggulan)
Sistem menggunakan AI untuk memprediksi pertumbuhan kambing.

### Cara Menjalankan
- **Web**: Di daftar kambing, klik tombol kuning **AI Prediksi**. Tunggu progres bar hingga 100%.
- **Mobile**: Buka detail kambing, klik **JALANKAN ANALISIS & FORECAST**.

### Cara Membaca Hasil
- **Forecast Grafik**: Garis/batang biru menunjukkan estimasi kenaikan berat badan bulan depan.
- **Skor Kesehatan**: Menunjukkan tingkat kesehatan ternak (0-100).
- **Rekomendasi AI**: Baca saran tertulis dari AI mengenai pakan atau tindakan medis yang diperlukan.

## 5. Ekspor Data
Untuk laporan mingguan/bulanan:
- Buka menu **Profil** di Mobile App.
- Pilih **Ekspor Data Ternak (CSV)**.
- File CSV akan diunduh ke perangkat Anda.

## 6. Sinkronisasi Data
Jika Anda menggunakan Mobile App di area tanpa sinyal:
- Input data seperti biasa (disimpan lokal).
- Saat kembali ke area bersinyal, klik ikon **Sync (Dua Panah)** di Beranda.
- Pastikan semua antrean terkirim ke server.
